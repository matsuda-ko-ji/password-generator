# Password Generator

## 概要
パスワードを安全にランダム生成するためのシンプルな Web ツールです。  

## 機能
- パスワードのランダム生成
- パスワード長の指定
- 使用する文字種の選択
  - 英大文字
  - 英小文字
  - 数字
  - 記号
- 生成結果の表示
- ワンクリックでコピー

## 使用技術
- HTML
- CSS
- JavaScript（フレームワーク不使用）

## 設計方針
- ロジックとUIを分離し、保守しやすい構成を意識
- 小規模アプリでも設計を行ってから実装
- 将来的な機能追加（生成履歴の保存）を考慮した構成

## 今後の拡張予定
- パスワード生成履歴の保存（DB連携）

## 動作確認
以下の観点で動作確認を行っています。

- パスワード生成が正常に行われる
- 各文字種のON/OFFが反映される
- 入力値のバリデーションが機能する
- コピー機能が正常に動作する
